📊 Sales Performance Dashboard | Power BI

📌 Project Overview

The Sales Performance Dashboard is an interactive business intelligence project developed using Microsoft Power BI. It helps analyze sales performance, profitability, customer behavior, product performance, and sales targets through dynamic visualizations and KPIs.

The project uses a sample sales dataset covering the year 2025, with financial values represented in INR (₹).

🎯 Business Objectives
Monitor overall sales and profit performance.
Track total orders and customer activity.
Analyze monthly sales trends.
Evaluate profit margins.
Compare sales performance against targets.
Identify high-performing products and customer segments.
Understand sales pipeline performance.

🛠️ Tools & Technologies
Microsoft Power BI Desktop
Power Query – Data Cleaning and Transformation
DAX – Measures and Calculations
Data Modeling – Table Relationships
Microsoft Excel – Source Dataset

📂 Dataset Description
The project uses the following tables:
Table
Description
Sales
Order-level sales, quantity, revenue, cost and profit
Customers
Customer details, segments and cities
Products
Product names, categories and subcategories
Targets
Monthly sales targets
Deals
Sales pipeline and deal information
DateTable
Calendar table for time-based analysis

📐 Data Modeling
The project uses a relational data model with one-to-many relationships.
Customers → Sales
Customers → Deals
Products → Sales
DateTable → Sales
DateTable → Deals
DateTable → Targets
