## 📌 Project Overview

The Sales Performance Dashboard is an interactive Business Intelligence project developed using Microsoft Power BI.

It provides an overview of sales performance, profitability, customer activity, product performance, sales targets, and sales pipeline through interactive visualizations and KPI metrics.

The project uses a practice dataset covering the year 2025, with financial values represented in Indian Rupees (₹).

## 🎯 Business Objectives

- Monitor overall sales and profit performance.
- Track total orders and customer activity.
- Analyze monthly sales trends.
- Evaluate profit margins.
- Compare sales performance against targets.
- Identify product and customer segment performance.
- Monitor open sales pipeline opportunities.

## 🛠️ Tools & Technologies

- Microsoft Power BI Desktop
- Power Query
- DAX (Data Analysis Expressions)
- Data Modeling
- Microsoft Excel

## 📂 Dataset Description

| Table | Description |
|---|---|
| Sales | Order-level sales, quantity, revenue, cost and profit |
| Customers | Customer names, segments and cities |
| Products | Product names, categories and subcategories |
| Targets | Monthly sales targets |
| Deals | Sales pipeline and deal information |
| DateTable | Calendar table for time-based analysis |

## 🔗 Data Model

The project uses a relational data model with one-to-many relationships:

- Customers → Sales
- Customers → Deals
- Products → Sales
- DateTable → Sales
- DateTable → Deals
- DateTable → Targets
